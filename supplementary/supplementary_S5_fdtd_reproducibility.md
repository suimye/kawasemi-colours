# Supplementary S5 — FDTD reproducibility, convergence and boundary-condition caveats

This supplement documents the 3-D finite-difference time-domain (FDTD) runs
referenced in Methods §2.8 and Results §3.5, including their software
environment, exact commands, geometry and boundary conditions, resolution and
smoothing sensitivity, and seed-specific results. The runs are retained only as
a preliminary full-Maxwell cross-check: they are neither independent nor
quantitative validation because the reported peaks are not numerically
converged and the small structure is laterally periodic.

## S5.2 Structure generation (fixed across all runs unless stated)

The 3-D keratin/air voxel volume is generated by `model/structure3d.py`:

```python
structure3d.generate_volume(d_nm, pore_fraction=0.5, disorder=0.12,
                             nm_per_vox=22.0, size=vox, seed=seed)
```

`d_nm` is the target characteristic spacing, `size=vox` is the number of
voxels per side (24 throughout, i.e. a 24×24×24 volume, 22 nm/voxel →
528 nm per side, **≈2.9 periods per side** for d = 185 nm). `seed` selects
one specific quasi-random disorder realisation; the committed script
(`model/fdtd3d_meep.py`) exposes this as `--seed` (default 1), and exposes
the MaterialGrid sensitivity setting as `--subpixel-smoothing`; the
multi-seed and smoothing runs in §S5.5 can therefore be reproduced directly.

## S5.3 MEEP simulation setup (`model/fdtd3d_meep.py`)

- **Cell**: `sx = sy = L`, `sz = L + 2*(dpml + pad)`, where `L` = structure
  side in MEEP units (a = 1000 nm), `dpml = 1.0` (a-units, i.e. 1000 nm),
  `pad = 0.6` (600 nm). For the standard d = 185 nm / vox = 24 / 22 nm-per-vox
  case, `L = 0.528 a` (528 nm), so `sz ≈ 3.728 a`.
- **PML**: `mp.PML(dpml, direction=mp.Z)` — absorbing boundary **only along
  z** (the propagation direction). No PML in x or y.
- **Lateral boundary condition**: `k_point = mp.Vector3()` (i.e. k = 0). With
  no PML in x/y, this makes the simulation **Bloch-periodic in x and y at
  normal incidence** — MEEP tiles the single 528 nm × 528 nm disordered block
  **periodically to infinity** in the lateral directions. **This is not a
  finite, isolated disordered sample**; it is an infinite periodic array of
  one particular finite random tile. For a quasi-ordered but genuinely
  aperiodic biological structure, periodic tiling of a small tile (here
  ≈2.9 periods per side) can introduce spurious long-range order and
  artificial coherence at the tile boundary that would not be present in a
  real, non-periodic feather cross-section or in an ensemble/finite-domain
  experiment. We flag this explicitly as a modelling approximation, not a
  property of the real material.
- **Source**: `mp.GaussianSource(fcen, fwidth=df)`, `component=mp.Ex`, a
  normal-incidence plane wave spanning the full lateral cell
  (`size=mp.Vector3(sx, sy, 0)`), placed at `src_z = -0.5*sz + dpml + 0.2`.
- **Frequency range**: λ = 0.36–0.78 μm (360–780 nm), `fcen`/`df` set from
  `fmin=1/0.78`, `fmax=1/0.36`; `nfreq = 100` flux points.
- **Material**: `keratin = mp.Medium(index=1.56)`, air = `mp.air` (n = 1.0);
  the voxel volume is supplied to `mp.MaterialGrid(..., weights=design)`
  (design = flattened 0/1 voxel array). `do_averaging` is left at the MEEP
  default (`False`, i.e. no subpixel smoothing) unless
  `--subpixel-smoothing` is passed.
- **Two-step reflectance recipe**: (1) an empty (`default_material=mp.air`)
  normalisation run records the incident flux and flux data via
  `sim.get_flux_data`; (2) `sim.reset_meep()`, then a second run with the
  structure geometry uses `sim.load_minus_flux_data` to obtain the reflected
  flux; `R(λ) = -reflected/incident`.
- **Termination**: `mp.stop_when_fields_decayed(20, mp.Ex, (0,0,refl_z), 1e-3)`
  in both runs.

## S5.4 Exact commands

Baseline run reported in the main text (Methods §2.8 / Results §3.5),
resolution = 24, seed = 1:

```
cd model
python fdtd3d_meep.py --d 185 --vox 24 --nm-per-vox 22 --res 24
```

Resolution-sweep commands (same d/vox/nm-per-vox, `--res` varied):

```
python fdtd3d_meep.py --d 185 --vox 24 --nm-per-vox 22 --res 24
python fdtd3d_meep.py --d 185 --vox 24 --nm-per-vox 22 --res 36
python fdtd3d_meep.py --d 185 --vox 24 --nm-per-vox 22 --res 50
```

Subpixel-smoothing commands (`--subpixel-smoothing`) for Table 2 are:

```
python fdtd3d_meep.py --d 185 --vox 24 --nm-per-vox 22 --res 24 --seed 1 --subpixel-smoothing
python fdtd3d_meep.py --d 185 --vox 24 --nm-per-vox 22 --res 36 --seed 1 --subpixel-smoothing
python fdtd3d_meep.py --d 185 --vox 24 --nm-per-vox 22 --res 50 --seed 1 --subpixel-smoothing
```

The Table 3 seed sweep uses the same command with `--seed 1`, `--seed 2`, or
`--seed 3`, and `--d 140` or `--d 250`, at `--res 24
--subpixel-smoothing`. All other parameters (cell, PML, source, frequency
range, termination) are unchanged from §S5.3.

## S5.5 Results

**Table 1 — resolution sweep, no subpixel smoothing (as committed;
d = 185 nm, pore fraction 0.5, disorder 0.12, vox = 24, 22 nm/voxel, seed = 1).**
Analytic 3-D structure-factor prediction for the same nominal parameters
(`structure3d.colour_3d`, size = 48 for finer sampling): **540 nm**.

| Resolution (px/µm) | Peak wavelength |
|---:|---:|
| 24 | 477 nm |
| 36 | 381 nm |
| 50 | 576 nm |

**Not converged**: the peak varies by 195 nm (381–576 nm) across this
resolution range with no monotonic trend.

**Table 2 — resolution sweep, with subpixel smoothing (`do_averaging=True`;
same parameters as Table 1).**

| Resolution (px/µm) | Peak wavelength |
|---:|---:|
| 24 | 576 nm |
| 36 | 581 nm |
| 50 | 473 nm |

Smoothing changes the individual values substantially relative to Table 1
and is **also not converged** (108 nm spread, non-monotonic).

**Table 3 — seed sensitivity at fixed resolution (24 px/µm, `do_averaging=True`),
individual results and summary statistics, for a blue-producing and a
red-producing spacing.**

| d (nm) | seed 1 | seed 2 | seed 3 | mean | SD |
|---:|---:|---:|---:|---:|---:|
| 140 | 401 nm | 360 nm | 362 nm | 374.3 nm | 19.1 nm |
| 250 | 608 nm | 670 nm | 663 nm | 647.0 nm | 27.6 nm |

n = 3 seeds per spacing; not sufficient to establish a statistically robust
trend, but consistent with larger dispersion at the longer (redder) spacing.
The 2-D realisation-to-realisation analysis is reported in main text §3.4,
Figure 6B; its dispersion does not increase monotonically with spacing.

## S5.6 Interpretation and what would be needed for a quantitative claim

Across Tables 1–2, six independent (resolution × smoothing) settings for the
*same* nominal geometry (d = 185 nm) give peaks ranging from 381 to 581 nm —
a span that covers most of the blue-to-orange visible range. This is not
resolution convergence in any usable sense, and the review comment's
conclusion is correct: as currently run, the FDTD results cannot support a
claim of "independent quantitative (or even independent qualitative)
verification" against the analytic structure-factor prediction or against
real plumage colour.

Causes we can identify from the data above:

1. **Small simulation volume.** 24 voxels at 22 nm/voxel = 528 nm per side is
   only ≈2.9 periods of a 185 nm structure; coherent scattering from
   disordered media is known to show large sample-to-sample (mesoscopic /
   speckle) fluctuations at this size, before any numerical-resolution issue
   is considered.
2. **Periodic (not finite) lateral boundary** (§S5.3): the simulation is a
   perfectly periodic tiling of one small random tile, not a finite or
   ensemble-averaged random medium — a structural mismatch with the physical
   system being modelled, independent of resolution.
3. **Under-resolution of the 22 nm voxel grid.** At resolution 24 px/µm the
   MEEP pixel size (≈41.7 nm) is coarser than the material's own 22 nm voxel
   spacing; subpixel smoothing (Table 2) changes the answer but does not fix
   convergence, consistent with the dominant source of variability being
   (1)-(2) rather than smoothing alone.

**What full convergence would require:** resolution swept well past the
point where results stop changing (likely ≥100 px/µm here, at much higher
compute cost), a lateral cell several periods larger with either absorbing
(not periodic) lateral boundaries or explicit ensemble averaging over many
periodic tiles, and averaging over many disorder realisations at each
resolution (as begun in Table 3, but with far more than 3 seeds). This is
identified as future work; it has not been done here.

## S5.7 Resulting change to the main text

Given the above, the manuscript text has been revised to:

- Remove "independent qualitative confirmation" / "independent
  verification" framing for FDTD.
- Describe the FDTD run as a full-Maxwell check on the same geometry that
  lands in the same general part of the visible spectrum as the analytic
  prediction, explicitly **not** an independent, converged, or quantitative
  validation, with this supplement cited for the reproducibility and
  convergence data.
- Note the periodic-boundary caveat (§S5.3) alongside the resolution
  non-convergence (Tables 1–2) as two distinct, compounding limitations.
- Retain FDTD in the paper (per the authors' judgement that it is a
  useful part of the physics-based modelling narrative) but reclassify it in
  the Discussion/Limitations as a capability under active development
  rather than a completed validation, with the specific next steps of
  §S5.6 named as future work.
